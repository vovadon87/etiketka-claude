# Выгрузки семантики (Яндекс Wordstat)

Исходные файлы владельца — **не редактировать**, навык читает их только на чтение (`wordstat_io.py`).

- `Семантика_косметика/` — ядро для /etiketki-dlya-kosmetiki-parfyumerii: Наклейки_косметика_парфюмерия_семантика.xlsx (частотности Россия 225, собрано 2026-10-15/16 через MCP wordstat_*), целевые фразы, минус-слова/фразы.
- `Семантика_наклейки/` — ядро «наклейки» (Россия) для /naklejki: Семантика_наклейки_Россия.xlsx, минуса по группам.

При запуске агента в облаке указывать путь к нужному файлу как `wordstat_source`. Актуальная копия — у владельца в `Downloads/Этикетки/Семантика_*`; при обновлении выгрузок синхронизировать сюда коммитом.
