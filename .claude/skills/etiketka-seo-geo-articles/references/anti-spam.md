# Анти-спам и защита от «Баден-Бадена»

Ориентир — справка Яндекса о переоптимизации: https://yandex.ru/support/webmaster/ru/threat/seo-text. Механическая часть проверок — `scripts/quality_checks.py`; ручная — по спискам ниже. Искусственные показатели «тошноты» универсальным критерием не считать: решение принимается по смыслу, скрипт лишь подсвечивает кандидатов.

## Что выявлять (Gate 7)

- Запросный спам: фразы, вставленные ради вхождения, не ради смысла.
- Избыточное повторение фраз и главного ключа; повтор одинаковых определений.
- Переспам заголовков (ключ в каждом H2; заголовки из склеенных ключей).
- Неестественные словоформы («этикетки Москва купить недорого»).
- Бессмысленные перечисления и «простыни» синонимов.
- Повтор одной мысли в разных разделах; дублирующиеся абзацы.
- SEO-текст ради объёма (абзац не проходит проверку полезности — удалить).
- Искусственные географические перечисления («в Москве, СПб, Казани, Новосибирске…»).
- Скрытый контент; пустые информационные блоки; нерелевантный FAQ.

## Шаблонные AI-обороты — удалять (и не заменять такими же)

«В современном мире…», «На сегодняшний день…», «Широкий спектр решений…», «Важную роль играет…», «Индивидуальный подход…», «Высокое качество по доступной цене…», «Наша компания предлагает…», «Стоит отметить…», «Не секрет, что…», «Давайте разберёмся…», «Ключевым аспектом является…», «Подводя итог…». Замена — конкретное утверждение с фактом, либо удаление фразы целиком.

## Контроль повторов

Проверять: повторение одних преимуществ в разных разделах · повтор главного ключа без необходимости · одинаковые определения · дублирующиеся абзацы · несколько разделов с одним интентом. Найден переспам → переработать текст (не «разбавить», а переписать по смыслу) и повторить проверку.

## Скрипт

`python scripts/quality_checks.py <файл.md>` — отчёт: топ повторяющихся н-грамм, доля самой частой леммы, подозрительные заголовки, найденные шаблонные обороты, похожие абзацы. Выход скрипта — сигналы для ручного решения, не вердикт.
