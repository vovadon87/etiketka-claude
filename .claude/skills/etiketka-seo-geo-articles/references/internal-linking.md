# Перелинковка и защита от каннибализации

## Карта соответствия (до написания, Gate 9)

Для каждого кластера назначить один основной URL: **кластер → целевая страница → поддерживающие материалы → внутренние ссылки**. Актуальный список страниц — sitemap и `audit-seo-geo/sites/etiketka/site-context.md` (раздел «Страницы»).

Для etiketka.express различать: общие страницы печати наклеек (`/naklejki`) · коммерческие страницы этикеток (`/`) · отраслевые страницы (`/etiketki-dlya-kosmetiki-parfyumerii`) · будущие страницы материалов · экспертные статьи. Известное пересечение: главная и /naklejki делят одно содержание (реестр противоречий №5) — новые тексты не должны углублять это пересечение.

## Правила против каннибализации

- Один интент — один основной URL. Статья по кластеру, закреплённому за другой страницей, не создаётся; вместо неё — ссылка.
- Не создавать почти одинаковые страницы под перестановки ключей и искусственные региональные дубли (правило из базового навыка: без «город × материал × товар»).
- Новая страница — только при отдельном намерении, самостоятельной ценности и ≥60 % уникального содержания (критерий semantic-content.md).
- Перед публикацией сверить H1/title/главные фразы новой статьи с существующими страницами; пересечение главных фраз = доработка.

## Требования к каждой внутренней ссылке

URL (существование проверено — запросом или по sitemap; ссылки не выдумывать) · анкор (естественный, не ключ-склейка) · причина (какую задачу читателя закрывает переход) · рекомендуемое место в тексте · релевантный интент.

## Выход

`13_CANNIBALIZATION.md`: таблица пересечений (фраза/кластер → наша статья → конкурирующий URL сайта → риск → решение) + список рекомендованных внутренних ссылок с полями выше.
