# Анализ выдачи Яндекса и поискового интента

## Зачем

Формат статьи выбирает выдача, а не автор. Перед написанием — проверка реальной выдачи Яндекса по приоритетным кластерам (Россия, Москва, СПб отдельно, если доступно).

## Главное правило

**Не продвигать информационную статью по запросу, где выдача коммерческая.**
- Выдача коммерческая (услуги, каталоги, карточки организаций) → усиливать посадочную страницу (режим on-page).
- Выдача информационная (статьи, обзоры) → отдельная экспертная публикация (режим blog).
- Смешанная → выбранную структуру обосновать в `03_SERP_INTENT.md`.

## Как проверять

1. Доступ: браузер сессии → yandex.ru, регион выставить/зафиксировать. CAPTCHA не обходить; появилась — записать «выдача не проверялась, причина: капча» и работать по косвенным сигналам (формулировка фразы, связанные запросы Wordstat, подсказки).
2. По каждому основному интенту — до 10 органических результатов. Рекламу (метка «Реклама»/«Промо») в анализ не включать.
3. Фиксировать: дату, регион, залогинен/инкогнито, устройство.

## Что извлекать из каждого результата

Title · H1 · структура H2/H3 (если страница открыта) · тип страницы (коммерческая / статья / категория / карточка организации / агрегатор) · глубина раскрытия · коммерческие элементы (цены, калькуляторы, CTA) · таблицы · FAQ · производственные факты · примеры/кейсы.

Отдельно отмечать: AI-ответ (Нейро) над выдачей — есть/нет, какие источники цитирует.

## Классификация интента

| Интент | Признаки | Действие |
|---|---|---|
| Transactional | «заказать», «купить», «печать … цена» | посадочная |
| Commercial investigation | сравнение подрядчиков/материалов перед заказом | посадочная + экспертный блок |
| Informational | «как», «какой выбрать», «почему отклеивается» | статья/FAQ со ссылкой на посадочную |
| Informational-commercial | вопрос, за которым стоит заказ | экспертный блок на посадочной или статья с CTA |
| Navigational | бренд, адрес | главная/контакты |
| Irrelevant | другой продукт (маникюр, стикерпаки, термонаклейки) | исключить, кандидат в минус-слова |

## B2B-подклассификация (для приоритизации, не для исключения)

Производитель · владелец бренда · контрактное производство · закупщик · технолог · дизайнер упаковки · оптовик · конечный розничный покупатель (не исключать автоматически: микробренды и «домашняя косметика» — целевые при тираже от 50 шт; чистый розничный DIY — низкий приоритет).
