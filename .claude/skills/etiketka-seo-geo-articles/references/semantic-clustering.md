# Кластеризация и приоритизация запросов

Базовая процедура сбора и направлений — `audit-seo-geo/references/semantic-content.md` (не дублировать). Здесь — правила кластеризации для статьи и модель приоритета.

## Нормализация и очистка

1. Дедупликация по нормализованной форме (лемматизация упрощённая: `scripts/wordstat_io.py`).
2. Исключать: дубли; другой продукт (декоративные наклейки, стикерпаки, термонаклейки, платёжные стикеры); очевидно нецелевые интенты; продукцию, которую компания не производит; необоснованный B2C (DIY-наклейки для себя — отдельно оценить).
3. **Не исключать** фразу только из-за слова «наклейки» вместо «этикетки» — владелец подтвердил: один продукт (site-context.md).
4. Исключённое не удалять — лист «Нецелевые» с причиной и кандидатом в минус-слова.

## Кластеризация

Кластер = группа фраз с одним интентом и одной задачей пользователя, закрываемая одним разделом/страницей. Признаки объединения: общий объект (тара, вид продукции, материал, условие) + совместимый интент. Для каждого кластера: название, главная задача пользователя, главная фраза (максимальная подтверждённая частотность), целевой URL.

## Semantic Opportunity Score (внутренняя модель, не алгоритм Яндекса)

Балл 0–100 на кластер, веса фиксированы для воспроизводимости:

| Фактор | Вес | Шкала |
|---|---:|---|
| Релевантность продукту компании | 25 | 0 — нет / 13 — частично / 25 — прямое совпадение |
| Подтверждённый спрос (широкая частотность главной фразы) | 20 | 0 — нет данных / 5 — <10 / 10 — 10–100 / 15 — 100–1000 / 20 — >1000 |
| Коммерческий интент | 20 | 0 — информационный без выхода на заказ / 10 — инф.-коммерческий / 20 — коммерческий |
| Потенциал заявки (B2B-аудитория) | 15 | 0–15 по подклассификации |
| Текущий охват страницей | 10 | 10 — не раскрыт / 5 — частично / 0 — уже раскрыт |
| Риск каннибализации | 10 | 10 — нет / 5 — управляемый (ссылкой) / 0 — высокий |

Конкурентность учитывается только при реальных данных (проверенная выдача) — как заметка, не как слагаемое. Балл — для сортировки работ; в публикуемые тексты и обещания не попадает.

## Выход

`05_SEMANTIC_MAP.xlsx` / CSV: кластер → интент → фразы (с частотностями и источниками) → задача пользователя → целевой URL → Opportunity Score → решение (раскрыть в статье / отдельная страница / не использовать). Суммы частотностей — с оговоркой о пересечении.
