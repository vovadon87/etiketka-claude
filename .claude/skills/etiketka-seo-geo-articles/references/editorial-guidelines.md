# Редакторские правила статей

Базовые правила текстов (B2B-стиль, запреты на выдумывание) — `audit-seo-geo/SKILL.md` и `references/semantic-content.md`. Здесь — специфика статей.

## Стиль

Профессиональный, точный, естественный, предметный. Как материал специалиста производственной компании: конкретные параметры, причины, следствия. Без канцелярита, без искусственной рекламности, без шаблонных нейросетевых оборотов (список — `anti-spam.md`).

## Структура

- Информативное вступление: сразу о задаче читателя, без «в современном мире». 2–4 предложения.
- Логичные H2, H3 — при необходимости. Заголовки — о задаче/вопросе читателя, не склейка ключей.
- Прямые ответы (answer-first), полезные сравнения, таблицы — где они короче текста.
- Проверяемые технические сведения (fact-check) и обоснованные коммерческие аргументы.
- Естественный CTA из реально доступных действий сайта (см. «Конверсия»).
- **Статья внутри существующей страницы — без второго H1** (только H2/H3). Отдельная публикация — один H1.

## Интеграция ключевых запросов

Принцип: **запросы определяют, какие вопросы раскрывает статья, а не сколько раз повторить слова.**
- Использовать основные коммерческие формулировки, естественные словоформы, синонимы (этикетка/наклейка — по базовому слову страницы: на /naklejki — «наклейки», на остальных — «этикетки», правило из semantic-content.md), тематические термины, вопросы пользователей, конкретные характеристики.
- Не добиваться точного вхождения каждого ключа; не составлять заголовки из ключевых фраз подряд; не управлять «плотностью».

## Semantic Coverage Matrix (после написания)

| Кластер | Частотность (главная фраза, источник) | Интент | Раздел статьи | Статус |
|---|---|---|---|---|

Статусы: раскрыт полностью / раскрыт частично / не раскрыт / не подходит странице / требуется отдельная страница. Проверка — по смыслу, не по вхождению.

## Конверсия (Gate 10)

Для каждой статьи ответить: что пользователь хочет заказать · что мешает решению · какую информацию ищет · критерии выбора · какие аргументы подтверждены · какой CTA уместен. Доступные CTA сайта (сверять с site-context.md, раздел «Конверсионные действия»): рассчитать стоимость тиража (квиз) · бесплатный пробный образец · подобрать материал · отправить макет на расчёт · позвонить/написать в мессенджер. Только реальные действия; статью не превращать в рекламную листовку — один-два CTA по смыслу раздела.

## Определение объёма

Фиксированного объёма нет. Объём = минимум, достаточный для полного ответа; определяется интентом, числом содержательных кластеров, сложностью темы, доступной экспертизой, конкурентной выдачей и тем, что уже есть на странице. Для коммерческого лендинга — компактный экспертный блок; для самостоятельной технической статьи — подробное раскрытие. Решение и обоснование — в content brief.
