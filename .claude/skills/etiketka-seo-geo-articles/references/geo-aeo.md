# GEO/AEO для статей: пригодность для генеративных ответов

База (роботы, критерии страницы, протокол проверочных запросов) — `etiketka-seo-geo/references/geo.md`; не дублировать. Здесь — то, что делает **статью** пригодной для ответов ИИ (Алиса AI, Нейро, Google AI Overviews, ChatGPT Search, Perplexity). GEO = Generative Engine Optimization; не путать с региональным SEO. Ничто из этого не гарантирует цитирование — формулировать как механизм, не обещание.

## Answer-First

Для каждого конкретного вопроса: сначала прямой ответ (1–2 предложения), затем условия → причины → сравнение → ограничения → практические рекомендации. Заголовок-вопрос, под ним сразу ответ, не «подводка».

## Autonomous Answer Units

Смысловые фрагменты 40–90 слов, понятные вне статьи. Каждый фрагмент:
- раскрывает одну тему и содержит конкретный ответ;
- называет условия применимости («для флаконов, которые стоят в ванной…»);
- не искажает технические факты при вырывании из контекста (проверить: прочитать фрагмент изолированно);
- самодостаточен: понятно, о каком продукте/материале речь, без «он/это» с отсылкой к прошлому абзацу.

**Не превращать весь текст в FAQ** — units встроены в разделы; FAQ-блок отдельно и только с вопросами, имеющими подтверждённый спрос или реальную частоту у клиентов.
