# Семантика, архитектура и контент

Направления исследования (виды продукта, материалы, отрасли, тара, условия, регионы) для конкретного сайта — в `sites/<имя>/profile.md`. Это направления поиска, а не подтверждённый ассортимент.

## Намерения
Коммерческое (заказать, цена, купить, подрядчик) → посадочные. Информационное (как выбрать, как подготовить) → FAQ/статьи со ссылкой на коммерческую. Навигационное/брендовое → главная, контакты.

## Процедура
1. Собрать запросы: Wordstat (`wordstat_suggest`, `wordstat_regions`, `wordstat_dynamics`), отчёт Директа «Поисковые запросы», Вебмастер «Запросы». Без данных семантика **предварительная**, частотность не указывать.
2. Сопоставить с существующими страницами сайта. Найти пересечения и каннибализацию (две страницы на один интент).
3. Таблица: Кластер → намерение → запросы → текущий URL → действие (оставить / доработать / объединить / создать) → приоритет.
4. Новая страница только при отдельном намерении, самостоятельной ценности (своя тара, условия, кейсы) и ≥60 % уникального содержания. Без массовых «город × материал × товар».

## Wordstat: как читать
- «total» у фразы — частотность широкая; кавычки и «!» — точная. `null` — нет данных, не ноль.
- Отдельно отмечать шум: фразы про чужие товары, программы, принтеры, шаблоны и пр. — их не оптимизировать.
- Региональный срез (`wordstat_regions`) — для решения о региональных страницах; без него регион не обосновывать.
- Дата и параметры замера (период, устройства) фиксируются в отчёте.

## Правила текстов
- Стиль по профилю (для B2B — конкретика, материал и технология через задачу покупателя).
- Без плотности ключей, «SEO-абзацев» и искусственного объёма.
- Сроки, тиражи, показатели, цены — только со статусом ПВ/ОС из `site-context.md`; иначе `[ЗАПОЛНИТЬ: …]`.
- Базовая версия страницы использует одну формулировку товара; подмена по UTM только для рекламы.
- Структура коммерческой страницы: оффер → виды продукта/тара → материалы и варианты → как работаем → доверие и кейсы → примеры → отзывы → гарантии → вопросы → CTA → контакты.
- Вопросы покупателей берутся из поиска и обращений, а не придумываются.
