# Региональное SEO

## Подтверждённые регионы
- **Санкт-Петербург** — адрес Днепропетровская ул., 5; телефон 812; карточка в Яндекс Картах (ссылка в sameAs). Статус: ОС.
- **Москва** — адрес Смирновская ул., 4с2, телефон 495. Назначение объекта (офис, производство, выдача) не подтверждено — не называть «производством в Москве» без подтверждения.
- Остальные регионы — только доставка («доставка по России»). Страницы под города не создавать без самостоятельного спроса и локального содержания (адрес/выдача/логистика/кейсы региона).

## Различать
Офис · производство · пункт выдачи · территория доставки. Наличие телефона с кодом города — не доказательство офиса.

## Проверки NAP (название, адрес, телефон)
1. Одинаковые написания на всех страницах, в JSON-LD, в карточках Яндекс Бизнес/2ГИС/Google Business (если есть).
2. Страница/блок контактов: адреса, часы, реквизиты, карта, ссылка на карточку.
3. Подстановка региона по UTM не должна менять базовую версию для роботов (без параметров — СПб).
4. Телефон кликабелен (`tel:`), формат единый.
5. Отзывы в карточке Яндекс Карт — реальные; не копировать в разметку Review без основания.

## Карточки компании
- Яндекс Бизнес: подтверждение, категория «типография/печать этикеток», описание с материалами и условиями, фото тиражей, ссылка на сайт, время работы. Это основной локальный сигнал в Яндексе.
- Для Москвы — карточка только если объект реально существует и принимает клиентов/звонки.

## Региональные страницы (если решено)
Критерии: есть спрос в регионе (Вордстат по региону), есть локальное содержание (адрес, выдача, сроки доставки, кейсы из региона), уникальный текст. Иначе — региональные подстановки на существующих страницах (как сейчас) и Вебмастер → «Региональность» с привязкой к СПб (и Москве, если подтверждён адрес).
