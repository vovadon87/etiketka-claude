# Семантика, архитектура и контент

## Направления исследования (не подтверждённый ассортимент)
1. Виды и поставка: этикетки в рулонах, самоклеящиеся, наклейки, стикеры, контрэтикетки, круглые/фигурные.
2. Материалы: белая, прозрачная, серебристая плёнка, полуглянцевая бумага (только эти).
3. Технологии и отделка: цифровая, офсетная печать; матовая/глянцевая ламинация, soft touch; контурная высечка.
4. Отрасли: косметика и парфюмерия, бытовая химия, напитки, пищевая продукция, мёд, алкоголь (примеры есть в галереях).
5. Упаковка: флаконы, тубы, банки, дой-паки, канистры, коробки, пробники.
6. Условия: влага, масла, холод, ванная, перепады температуры.
7. Тираж, цена, сроки, макет: «малым тиражом», «цена», «срочно», «требования к макету».
8. Регионы: СПб, Москва; остальные — при подтверждённом спросе и обслуживании.

## Намерения
Коммерческое (заказать, печать, типография, цена) → посадочные. Информационное (как выбрать материал, клей, макет) → FAQ/статьи со ссылкой на коммерческую. Навигационное/брендовое → главная, контакты.

## Процедура
1. Собрать запросы (Wordstat вручную; `wordstat_etiketka.py` при наличии ключа Yandex Cloud; отчёт Директа «Поисковые запросы»; Вебмастер «Запросы»). Без данных семантика **предварительная**, частотность не указывать.
2. Сопоставить с существующими страницами: `/`, `/naklejki`, косметика. Найти пересечения (сейчас главная и /naklejki делят одно содержание).
3. Таблица: Кластер → намерение → запросы → текущий URL → действие (оставить / доработать / объединить / создать) → приоритет.
4. Новая страница только при отдельном намерении, самостоятельной ценности (своя тара, условия, кейсы) и ≥60 % уникального содержания. Без массовых «город × материал × товар».

## Правила текстов
- B2B-стиль, конкретика; материал и технология через задачу покупателя («прозрачная плёнка, чтобы флакон остался видимым»).
- Без плотности ключей, «SEO-абзацев» и искусственного объёма.
- Сроки, тиражи, показатели — только со статусом ПВ/ОС из `site-context.md`; иначе `[ЗАПОЛНИТЬ: …]`.
- Базовая версия страницы использует одно слово («наклейки» на /naklejki, «этикетки» на остальных); подмена по UTM только для рекламы.
- Структура коммерческой страницы: оффер (срок, минимальный заказ, образец) → виды тары → материалы и отделка → как работаем → доверие и кейсы → примеры → отзывы → гарантии → вопросы → CTA → контакты.
- Вопросы покупателей: материал под условия, клей, макет, цена и тираж, сроки, образец, несколько продуктов в одном заказе.
